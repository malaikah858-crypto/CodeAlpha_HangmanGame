# CodeAlpha Hangman Game

A simple text-based Hangman Game developed in Python using Google Colab as part of the CodeAlpha Python Programming Internship.

## Project Description

This project is a console-based Hangman game where the computer randomly selects a word from a list of 5 predefined words.

The player guesses the hidden word one letter at a time. The player can make a maximum of 6 incorrect guesses.

## Features

* 5 predefined words
* Random word selection
* One-letter-at-a-time guessing
* Correct and incorrect guess checking
* Maximum 6 wrong guesses
* Winning and losing conditions
* Simple console-based input and output

## Technologies Used

* Python
* Google Colab
* Random module
* Lists
* Strings
* Sets
* While loop
* If-else statements
* User input/output

## How the Project Works

1. The program randomly selects a word from the predefined word list.
2. The selected word is hidden from the player.
3. The player enters one letter at a time.
4. If the letter is correct, it is displayed in the word.
5. If the letter is incorrect, one wrong attempt is counted.
6. The player has a maximum of 6 wrong guesses.
7. The game ends when the player guesses the complete word or uses all allowed wrong guesses.

## How to Run

This project was created and tested in **Google Colab**.

1. Open Google Colab.
2. Open the Hangman notebook.
3. Run the Python code.
4. Enter one letter at a time when the program asks for a guess.
5. Continue until you guess the word or use all 6 wrong attempts.
